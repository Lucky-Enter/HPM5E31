# HPM5E 当前硬件基线

核对日期：2026-10-08。以下区分用户确认、文件事实和待核实事项；后续改板后需重新核对。

## 用户确认

- 原理图以 `E:\RM\硬件\硬件板子工程文件\HPM5E\hardware` 为准，不使用嵌套的 `HPM5E\HPM5E\hardware` 副本。
- 当前主控图中的值是 HPM5E3YIVK1；用户确认使用 HPM5E3Y 的合封 PHY0。
- ESC0_P0 接合封 PHY0；ESC0_P1 通过 MII 接外置 TJA1101B，两端口服务同一 EtherCAT 从站。
- `phy.kicad_sch` 的 U2 器件值 TJA1102B 是用户确认的标注错误；实际选型 TJA1101B。
- 已有实物，当前电控在调试 PHY0，报告无法连接内部 PHY，但具体失败层次未知。
- 本轮仅审查硬件原因，不分析固件。
- 用户希望明确停用合封 PHY1 后，它占用的引脚能否用于 UART 等其他外设。

## 厂商直接依据

资料根目录：`E:\RM\硬件\硬件板子工程文件\HPM5E\资料`。

`HPM5E00用户手册.pdf`，Rev0.4，第 58.2.1 节，印刷页 1146/1225，PDF 第 1193 页，原文：

> 注意，即使只使用 1 个内置以太网 PHY，另外一个内置以太网 PHY 所占用的 GPIO 也不能用作普通 GPIO 功能

同节要求偏置引脚通过 2.49 kΩ 接地，要求相关引脚选择模拟功能以避免干扰；MDIO 总线由两颗合封 PHY 共享，允许外置 PHY 的 MDIO 接入。共享总线仍需核对各器件的地址和电气状态。

第 58.2.2 节（PDF 第 1193～1194 页）说明：PHY 的 MII、时钟、复位通过封装内部 PV/PW IO 与主芯片连接，支持映射到 ESC P0/P1 或 ENET0。两颗 PHY 不是直接互连的无条件透明转发器，EtherCAT 端口之间的转发经过 ESC。

`HPM5E00片内MII PHY使用指南.pdf` 第 5、9～10 页说明 SiP 合封关系、外部引脚和内部 PV/PW 配置。不能把关闭软件初始化理解为解除合封电气连接。

`两下位机通讯的PHY芯片\TJA1101B.pdf`，Rev.1：第 5 页表 2 定义 17 脚 RXER、18 脚 RXDV 为输出；第 8 页说明正常 MII 接收必须有 RXDV 有效指示；第 23 页表 11 说明 CONFIG3/CONFIG2=00 选择普通 MII。模式配置电阻须允许这些复用脚在运行时输出，不应硬接地。

## 原理图核对结果

只读解析了外层 KiCad 原理图的器件引脚坐标、导线和跨页全局网络标签；对关键结论交叉核对用户截图及厂商手册。未运行 KiCad ERC，未核对 PCB 和实物焊接。

| 主芯片引脚 | 合封 PHY1 功能 | 当前原理图网络 | 判断 |
| --- | --- | --- | --- |
| PA16 / K1 | RD_N | UART4_TX | 与合封型号保留要求冲突 |
| PA17 / J1 | RD_P | UART4_RX，连接 U3 的 4 脚输出 | 与合封型号保留要求冲突 |
| PA18 / J2 | TD_N | DBUS_CTRL，连接 U3 的 1 脚及 R23 | 与合封型号保留要求冲突 |
| PA19 / H1 | TD_P | 未发现外部功能网络 | 不能因未使用 PHY1 而改作其他外设 |
| PA24 / G3 | RBIAS | UART6_TX，无 PHY1 的 2.49 kΩ 偏置连接 | 与合封型号保留要求冲突 |
| PA25 / F1 | LED1/地址位 | UART6_RX | 与合封型号保留要求冲突 |
| PA26 / F2 | LED0/地址位 | 未发现外部功能网络 | 不能因未使用 PHY1 而改作其他外设 |

PA30/PA31 是共用 MDIO/MDC，当前接 ESC0_MDIO/ESC0_MDC 和外置 U2，并分别有 R15/R16 4.7 kΩ 上拉。它们也不因停用 PHY1 而释放。

PHY0 的 PA27 / E1 在原理图上接 `PHY0_RB`，对应 `phy.kicad_sch` 的 R57=2.49 kΩ 到 GND。因此“没有 2.49 kΩ”必须分清 PA24 的 PHY1 偏置与 PA27 的 PHY0 偏置；实物 R57 是否装配未知。

外置 U2 的 17（RXER/CONFIG3）和 18（RXDV/CONFIG2）脚在原理图及用户截图中直接接 GND。主芯片 PF14 / K9 的 ESC0_P1_RXER 和 PF08 / G11 的 ESC0_P1_RXDV 只发现主芯片侧标签，未接到 U2 对应输出。18 脚硬接地、RXDV 信号未接到 ESC 是外置 P1 端口正常 MII 接收的明确硬件障碍；不要将此直接说成合封 PHY0 无法建立 Link 的已证实原因。

VIO_B01 图上接 3.3V；VDD_PHY0CAP 与 VDD_PHY1CAP 图上均有 10 µF+100 nF 去耦。图纸连接不证明实物电压或焊接正常。

## 当前故障判定边界

- 可以确认现有图纸存在硬件设计错误，停用合封 PHY1 的引脚不可按普通 UART/GPIO 使用。
- 可以确认外置 P1 的 RXDV 接线有错误。
- 尚不能证明上述错误就是合封 PHY0 调试失败的唯一原因，也不能仅凭图纸判断芯片已损坏。
- 下一轮优先核实实物 R57 是否焊接且连通、PHY0 对端是否为兼容的 100BASE-TX、失败现象是 MDIO 不通还是物理 Link 不起。
- 不给出未经厂商证明的“PHY1 断电/复位即可释放引脚”方案。
